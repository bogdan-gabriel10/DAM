# DAM: Dispozitive și Aplicații Mobile

Seminarele de Android de la materia DAM, anul III, Informatică Economică, ASE București.
Java + XML, Android Studio.

## Seminare

| Seminar | Subiect | Ce conține |
|---------|---------|------------|
| [Seminar01](Seminar01) | Ciclul de viață al unei Activity | Toate metodele de lifecycle (de la `onCreate` la `onDestroy` și `onRestart`), urmărite cu `Log` și `Toast` |
| [Seminar02](Seminar02) | Formulare și View Binding | Calculator de IMC: `EditText`, `RadioGroup`, `CheckBox`, validări, layout cu `ScrollView` + `LinearLayout` |
| [Seminar03](Seminar03) | Fragmente și navigare | Trei fragmente cu `FragmentManager` și back stack, date trimise prin `Bundle` (suma și produsul a două numere) |

## Cum rulezi un seminar

Deschide folderul seminarului (ex. `Seminar03`) în Android Studio cu **File > Open**, așteaptă sincronizarea Gradle și apasă **Run**.
